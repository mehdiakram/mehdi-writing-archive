Display a side button with internal or external link for wordpress site. You can customize the button text, font, font colors, hover color, position side (left/right) etc.

![bdt](http://s-plugins.wordpress.org/rt-side-button/assets/banner-772x250.png)  
  
**How install the plugin**

- Download the plugin from [WordPress plugin directory](http://wordpress.org/plugins/rt-side-button/)
- Upload the plugin to the **/wp-content/plugins/** directory
- Activate the plugin through the **Plugins** page in WordPress
- Go to**options page** and configure button
- Then **Save changes**.
