Windows 8 ships with a set of new backup and restoration tool like the refresh/reset option that let you keep settings that would be lost if you’d install the operating system a new on the PC. Sometimes though a refresh may be overkill as it is not keeping all data that has previously been installed on the system. A refresh won’t restore apps that you have installed for instance.  
![](http://farm9.staticflickr.com/8100/8472263433_dfef6f8e12_z.jpg)  
There is also a situation where you need to reinstall Windows but do not want to lose your installed app data and settings in the process. That’s where **Windows 8 Apps Data Backup** comes into play. It is a freeware program for Windows 8 that you can use to backup data from some or all applications to the local system.

To run this tools need [Microsoft .NET Framework 4.5](http://www.microsoft.com/it-it/download/details.aspx?id=30653) to run this apps [Download](http://goo.gl/YYdNB)
