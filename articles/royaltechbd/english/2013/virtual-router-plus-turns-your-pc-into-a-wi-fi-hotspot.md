If you are use laptop or your PC has Wireless LAN, you can Turn Your PC Into a Wi-Fi Hotspot.  There are many third party tools to create Virtual WiFi Hotspot, like; Connectify or mHotspot. Virtual Router Plus is another freeware and portable tools which turns any Windows 7 and Windows 8 computer into a Wi-Fi Hot Spot using Wireless Hosted Network technology.  
![](http://farm9.staticflickr.com/8230/8473224792_a28613f20a.jpg)  
The application has a simple interface where you can set the SSID, password and also select the shared connection.

Virtual Router Plus is a free, open source software based router for PCs running Windows 7, Windows 8, Windows Server 2008 and Windows Server 2012. Using Virtual Router Plus, users can wirelessly share any internet connection (Wifi, Cable Modem, LAN, Dial-up, Cellular, etc.) with any Wifi device (Laptop, Smart Phone, iPhone, iPod Touch,Android Phone, Zune, Netbook, wireless printer, etc.) These devices connect to Virtual Router just like any other access point, and the connection is completely secured using WPA2 (the most secure wireless encryption.)  
It support Windows 7 and Windows 8. [Download](http://www.virtualrouterplus.com)
