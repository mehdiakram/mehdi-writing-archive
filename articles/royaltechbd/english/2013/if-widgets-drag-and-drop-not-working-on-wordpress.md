Some times WordPress blog had an odd problem, all on the blog, worked just fine except the Widgets add new widget drag and drop functionality.  
After updating new version of wordpress missing drag and drop widget functionality neither, so need like using the enable Accessibility Mode button on top Widgets.Thus the common suggested fix that worked for most of the people who stumbled upon this annoying wordpress bug was to simply navigate to:

Appearance -> Widgets -> Screen Options -> Enable Accessibility Mode

If Screen Options not working you can manually Widget Access On/Off
