This is a supported plugin for for WooCommerce for wordpress users. After install this plugin add Bangladeshi Taka (BDT ৳) & local Payment getaway (bKash, DBBL Mobile Banking).

![BDT & Payment Gateways in WooCommerce](http://s-plugins.wordpress.org/bdt-2547-in-woocommerce/assets/banner-772x250.png?rev=748656)

**How install the plugin**

- Download the plugin from [WordPress plugin directory](http://wordpress.org/plugins/bdt-2547-in-woocommerce/)
- Upload the plugin to the **/wp-content/plugins/** directory
- Activate the plugin through the **Plugins** page in WordPress
- Configure **Bangladeshi Taka (BDT ৳)** in **WooCommerce > Setting > General**
- ConfigureLocal Payment getaway (bKash, DBBL Mobile Banking) in **WooCommerce > Setting** **> Payment Gateway**
