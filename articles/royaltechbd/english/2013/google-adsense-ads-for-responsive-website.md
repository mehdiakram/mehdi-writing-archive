Responsive web design is a simple & powerful technique that makes website look good across all screen sizes; like- desktop, Laptop, Pad, Mobile phones, Tablets etc.  
Google also recommends the responsive design approach for improved indexing since :it keeps your desktop and mobile content on a single URL.”  
![](http://farm9.staticflickr.com/8527/8514085411_ef80731948_b.jpg)

**Responsive Google Ads Code with JavaScript**

[code lang=”js”]  
<script type="text/javascript">  
var width = window.innerWidth || document.documentElement.clientWidth; google\_ad\_client = "ca-publisher-id"; if (width >= 800) {  
google\_ad\_slot = "Your Ad-unit for 728X60 Ad";  
google\_ad\_width = 728;  
google\_ad\_height = 60;  
}  
else if ((width < 800) && (width < 400)) {  
google\_ad\_slot = "Your Ad-unit for 300X250 Ad";  
google\_ad\_width = 300;  
google\_ad\_height = 250;  
}  
else {  
google\_ad\_slot = "Your Ad-unit for 468X60 Ad";  
google\_ad\_width = 468;  
google\_ad\_height = 60;  
}  
</script>  
<script type="text/javascript" src="http://pagead2.googlesyndication.com/pagead/show\_ads.js">  
</script>

[/code]

Just Replace ca-publisher-id & ad-units.
