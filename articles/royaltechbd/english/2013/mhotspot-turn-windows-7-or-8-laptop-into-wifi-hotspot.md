mHotspot is a freeware software which converts your windows 7 or 8 laptop into a virtual [wifi](http://blog.royaltechbd.com/tag/wifi/) router and creates a secure wifi hotspot. It is a portable software so no installation required.  
You can share single internet connection (LAN, Ethernet, Data-Card, 3G/4G) for multiple devices like laptops, smartphones, android phones, PDAs, Ipads etc.  
![](http://farm9.staticflickr.com/8376/8478194950_5f1c0460b5_b.jpg)  
To run this software you need to have .Net Framework 4.0. If you get any error on running mHotspot, download and install .Net 4.0 from [www.filehippo.com/download\_dotnet\_framework\_4/](http://www.filehippo.com/download_dotnet_framework_4/) here.  
[Download](http://www.mhotspot.com/)
