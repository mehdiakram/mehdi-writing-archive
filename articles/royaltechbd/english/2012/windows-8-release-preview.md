Microsoft today’s release [Windows 8 Release Preview for the public](http://windows.microsoft.com/en-us/windows-8/iso) is a sign of that. Microsoft Windows 8 Developer Preview offered in last September 2011 and then release consumer preview in February 2012.

![Win 8](http://farm8.staticflickr.com/7230/7341406966_e4b920494c_z.jpg "Windows 8 Release Preview")

Microsoft is also gearing up for Windows Store for Windows 8. Today’s release of Windows 8 Release Preview as final test release of Microsoft Windows 8.

If you are interested in downloading Windows 8 Release Preview then download from those following links and get your own copy.

### ISO Images

An ISO image must be converted into installation media stored on a DVD or an USB flash drive. Instructions are provided on this site. Developer tools are available for download from Microsoft [Windows Dev Center](http://msdn.microsoft.com/windows/apps/br229516).
