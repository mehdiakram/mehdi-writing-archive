Now adays online radio stations available where user can listen to songs by streaming. RadioZilla is a freeware software for Windows which gives you access to thousands of the world’s radio stations so you can find, listen and download to unlimited music, sports and talk radio.  
![rediozilla](http://farm8.staticflickr.com/7112/7642662180_9f1b903fcb_b.jpg)  
RadioZilla automatically saves every new track in a separate file with the corresponding file name or it can saves only favorite songs> User just click **save** button while listening to a track you can get it full even if you have started recording from the middle.  
If user like to listen to free Internet Radio, Online Radio or Web Radio, RadioZilla have the Online Radio Tuner which will play and record your favorite radio stations and display the album art of the artist if available.  
Save your money by getting all your favorite songs with RadioZilla, only at the cost of the program. RadioZilla is available for Windows XP SP3 32-bit, Windows XP SP3 64-bit, Windows Vista 32-bit, Windows Vista 64-bit, Windows 7 32-bit, Windows 7 64-bit and Mac OS X 10.6 and higher (only intel CPU). Download [RadioZilla](http://www.theradiozilla.com/) from their official website.
