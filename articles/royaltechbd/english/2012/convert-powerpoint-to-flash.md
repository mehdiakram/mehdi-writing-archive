iSpring is a freeware software to convert PowerPoint slideshow to Flash file. By using iSpring user can start creating online presentations, e-Learning courses, quizzes, and surveys easily.   
iSpring support PowerPoint .PPT, .PPTX, .PPS, .PPSX file format and convert to presentations to Flash (.SWF). It’s another feature is Add Flash movies and YouTube videos, Keep PowerPoint animations, trigger animations, custom slide aspect ratio, styles, audio, videos and Create a single Flash (.SWF) file with all resources embedded.
