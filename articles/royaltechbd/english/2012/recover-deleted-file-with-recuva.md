Recuva is a freeware software to restore files that have been deleted by accidentally, bugs, crashes or viruses from windows computer. This includes files emptied from the Recycle bin as well as images and other files format that have been deleted by user even memory cards.   
![recuva](http://farm8.staticflickr.com/7140/7477635166_1df01560ab_z.jpg)  
Restores all types of files, office documents, images, video, music, email, anything and supports FAT12, FAT16, FAT32, exFAT, NTFS, NTFS5 , NTFS + EFS file systems. Download **Recuva [www.recuva.com](http://www.piriform.com/recuva/download)**. Recuva rubs on Microsoft Windows 7, Vista, XP and 2000 including both 32-bit and 64-bit versions.
