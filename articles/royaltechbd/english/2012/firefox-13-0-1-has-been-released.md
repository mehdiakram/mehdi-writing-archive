Mozilla has just released a new version of Mozilla Firefox stable version 13.0.1. Mozilla fixed three bug in the Firefox 13.0.1. If you are using Firefox recently you may have noticed that a Flash upgrade has caused serious crash and freezing issues for some users.  
Existing Mozilla Firefox users should see update notifications once they start it up the next time. It is recommended user to update as early as possible, especially if Firefox is affected by any of the three bugs.  
![Firefox 13.0.1](http://farm8.staticflickr.com/7225/7391829868_94099b6a77_z.jpg)  
**Download Firefox 13.0.1**  
Mozilla Firefox 13.0.1 is [available](http://www.mozilla.org/en-US/) for download at their official Mozilla website.
