In Windows operating system some software is Installing updates automatically as soon as they are released is usually a good thing to do. Like Windows, Adobe, Google Chrome, Java, Skype or Firefox update automatically and using internet bandwidth background. So user get less bandwidth. But that requires some research on your end to find the configuration settings to do just that.  
![update freezer](http://farm8.staticflickr.com/7216/7372243760_95dab849f8_z.jpg)  
Update Freezer is a freeware software that helps to temporarily disable different kinds of automatic software updates on Windows operation system. The software has no bloatware, advertising or any other kind of bundled bloatware.  
Download the software from [www.updatefreezer.org](http://www.updatefreezer.org/)
