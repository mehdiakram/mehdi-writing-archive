TestDisk is a powerful free open source data recovery software. It was primarily designed to help recover lost partitions and make non-booting disks bootable again when these symptoms are caused by faulty software, certain types of viruses or human error. Deleted partition table recovery using TestDisk is really easy.  
![TestDisk](http://farm8.staticflickr.com/7107/7477669832_2eddca1ef0_b.jpg)  
TestDisk can Fix partition table, recover deleted partition, Fix FAT tables, Rebuild NTFS boot sector, Recover FAT32 boot sector from its backup  
Rebuild FAT12/FAT16/FAT32 boot sector, Recover NTFS boot sector from its backup, Locate ext2/ext3 Backup SuperBlock, Fix MFT using MFT mirror, Undelete files from FAT, NTFS and ext2 filesystem,Copy files from deleted FAT, NTFS and ext2/ext3 partitions.  
Download testdisk from [www.cgsecurity.org](http://www.cgsecurity.org/wiki/TestDisk_Download)
