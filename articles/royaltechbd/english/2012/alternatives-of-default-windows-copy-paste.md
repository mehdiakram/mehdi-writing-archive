The default Windows copy paste functionality is serves the purpose most of the time. Mainly no resume features  and multiple file copy-paste system. But **TeraCopy** is possible alternatives to it.  
![tc](http://farm9.staticflickr.com/8157/7613981448_0c2ab4405f.jpg)  
TeraCopy is a small free tools that is designed to help users copy and move files from one location to another at the maximum possible speed. [Download TeraCopy](http://codesector.com/teracopy/) and install then copy past any file/folder & automatically takes over the default Windows copying and saves a lot of time.
