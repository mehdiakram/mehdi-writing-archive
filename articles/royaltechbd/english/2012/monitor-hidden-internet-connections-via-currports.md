The current visiting website that you are visiting, but at the moment your computer may also connects to inbound and outbound sources and websites or applications running in the background that you are not watching. These website communications are harmless and using your bandwidth and some can be gateways for viruses and malware. So you need to monitor the background services that your computer uses.You can using [Nirsoft CurrPorts](http://www.nirsoft.net/utils/cports.html)software to monitor and kill the running sites or application.

CurrPorts is network monitoring tools that displays the list of all currently opened TCP/IP and UDP ports on local computer. Every port in the list and information about the process that opened the port is also displayed, with process name, path, version, process created time and the user that created it.
