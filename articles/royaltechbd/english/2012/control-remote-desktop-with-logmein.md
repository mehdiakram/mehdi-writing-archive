LogMeIn gives remote control of PC or Mac from any other computer via Internet connection. LogMeIn has paid and free service. Simply install LogMeIn on client computer to access, log into your account from another computer from website. And see client computers desktop and be able to use all the applications from remote computer.  
![Logmein](http://farm9.staticflickr.com/8428/7555051628_79f4abd819_z.jpg)  
Download & registration from [www.logmein.com](https://www.logmein.com). After install client pc add you account. Then when the pc is available online you can see the pc’s status from LogMeIn dashboard. So you can login the pc and access remotely.
