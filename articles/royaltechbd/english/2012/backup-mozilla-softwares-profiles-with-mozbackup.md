MozBackup is a simple freeware utility for creating backups of Mozilla software like Firefox, Thunderbird, Songbird, Sunbird, SeaMonkey, Suite, Flock, Spicebird and also Netscape profiles. It allows to backup and restore bookmarks, mail, contacts, history, extensions, passwords, cache etc.  
![MozBackup](http://farm8.staticflickr.com/7246/7524928834_c50c55ac91.jpg)  
Mozbackup is freeware (even for commercial use) and works on Windows 98/ME/NT/2000/XP/2003/Vista/7. Download Mozbackup from <http://mozbackup.jasnapaka.com>
