XAMPP is a open source software for webmasters with an easy way of installing an Apache web server on a computer system. The XAMPP is available for Windows, Linux, Mac and Solaris operating systems. It include MySQL, PHP and Perl. The new version of XAMPP 1.8.0 Released.  
![xampp](http://farm9.staticflickr.com/8425/7566138100_e4b6df2ce0.jpg)  
Download from [www.apachefriends.org](http://www.apachefriends.org/en/xampp.html). The new version (1.8.0) of XAMPP includes the following software updates: Apache 2.4.2, MySQL 5.5.25a, PHP 5.4.4, phpMyAdmin 3.5.2, FileZilla FTP Server 0.9.41, Tomcat 7.0.28 (with mod\_proxy\_ajp as connector), Strawberry Perl 5.16.0.1 Portable, XAMPP Control Panel 3.0.12 (from hackattack142)
