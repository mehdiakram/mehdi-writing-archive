If you are Bangladeshi it is good news for you to send free SMS to any Bangladeshi mobile number daily upto 25.  
First go to <http://www.shurjobarta.com> and register. You will get a email, click the email link to active then you get a code vis sms, put the code and complete registration.  
Then login and send SMS upto 110 characters.  
You can add number to Contacts and able to send group sms.  
You can also get sent SMS log from Barta Archive with search option.
