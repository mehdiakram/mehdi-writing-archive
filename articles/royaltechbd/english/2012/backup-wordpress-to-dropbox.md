If you are using [WordPress](http://blog.royaltechbd.com/category/web-developent/wordpress), you must backup your site database & folders to your mail automatically regularly. By using **BackUpWordPress** you can backup database & folder in hosting root folder and get zipped file in our mail. But when your zipped file size large to email you the plugin can not able to send you mail. By that time you can only Database backup. If you use **Backup WordPress to [Dropbox](http://blog.royaltechbd.com/tag/dropbox)** plugin you can backup your folder to your Dropbox account.  
![wpb2d](http://farm9.staticflickr.com/8288/7567096078_f8016ab91f_b.jpg)  
Download Plugin from <http://wordpress.org/extend/plugins/wordpress-backup-to-dropbox/> and details form Author site [www.wpb2d.com](http://www.wpb2d.com/)
