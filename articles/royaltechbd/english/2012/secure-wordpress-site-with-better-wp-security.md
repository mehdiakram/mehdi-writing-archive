**Better WP Security** is a security plugin for secure [WordPress](http://blog.royaltechbd.com/category/web-developent/wordpress) site. The plugin thereby ensuring that as many security holes as possible are patched without having to worry about conflicting features or the possibility of missing anything on wp site.  
![bws51](http://farm9.staticflickr.com/8001/7567274620_a583e2b1a1_b.jpg)  
Download Better WP Security from <http://wordpress.org/extend/plugins/better-wp-security/> and details from Author’s site [www.bit51.com](http://bit51.com/software/better-wp-security/)  
The main Features of **Better WP Security** is Scan site to instantly tell where vulnerabilities are and fix them in seconds, Remove the meta “Generator” tag, Removes error messages, Change the urls for backend functions, Create and email database backups on a customizable schedule, Prevent brute force attacks by banning hosts, Display a random version number, Enforce strong passwords, Detect attempts to attack your site, Rename “admin” account, Change the WordPress database table prefix, Change wp-content path and many more.
