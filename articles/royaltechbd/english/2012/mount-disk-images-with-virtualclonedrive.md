Virtual Clone Drive is a [freeware](http://blog.royaltechbd.com/tag/freeware) software to mount image just like a physical CD or DVD drive. Image files generated with any burning software and mounted onto a virtual drive from your hard-disk or from a network drive. Virtual Clone Drive supports all popular image formats like ISO, BIN, CCD etc. Supports all common image formats such as ISO, BIN, CCD and Supports up to 8 virtual drives at the same time. Easy to use – just double-click an image file to mount as a drive and Virtual CloneDrive is freeware, you may use it at no cost.  
![virtualclonedrive](http://farm9.staticflickr.com/8150/7524963672_5c135551dd.jpg)  
Download from [www.slysoft.com](http://www.slysoft.com/en/virtual-clonedrive.html). It support Windows 98, Windows ME, Windows 2000, Windows XP, Windows Vista or Windows 7 (32 or 64 bit)
