Generally image file show thumbnail in windows explorer. If you want to view pdf file as thumbnail you need to install [PDF](http://blog.royaltechbd.com/tag/pdf) preview software. PDF Preview allows users to thumbnail preview PDF file without open. This software is free adn support for Windows Explorer, Microsoft Office, and Microsoft Outlook and automatically configures itself to preview a PDF file in the Preview pane of Windows Explorer and in the Reading pane in Outlook 2007, 2010, 2012 and future versions. The first PDF page is shrieked as a thumbnail and you can zoom in if you double-click on the thumbnail.  
![pdf preview](http://farm6.staticflickr.com/5465/7364221438_31173707ce.jpg)  
**[Download PDF Preview](http://www.win7pdf.com/pdf-preview.html)**  
PDF Preview support Microsoft Windows 7 32-bit and 64-bit, Microsoft Windows Vista, Windows Server 2008 and Windows Server 2012.
