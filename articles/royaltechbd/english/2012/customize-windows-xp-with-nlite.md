nLite is a freeware tool for Customize Windows operation system. With nLite user will be able to have Windows installation which on install does not include or even contain on media, the unwanted components. Service Pack Integration, Component Removal, Driver Integration, Hotfixes Integration, Unattended Setup,  Tweaks, Services Configuration, Patches, Bootable ISO creation. nLite supports Windows 2000, Windows XP (x86/x64) and Windows 2003 (x86/x64) in all languages. nLite needs .NET Framework 2.0 for installation.
