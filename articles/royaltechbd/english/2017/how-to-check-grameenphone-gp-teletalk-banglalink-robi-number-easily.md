The tendency of forget number is a common matter among the user of mobile. We often forget mobile numbers it’s may our own or others numbers. So in today I will be going to share with you an article which can help you check your mobile number by dial some of digit. Doesn’t matter which operator you are used. From this post, you will learn how to check GP, Robi, teletalk even the banglalink.

**GP number check**  
If you’re a user of Bangladeshi leading telecom company Grameenphone, then you can check your phone number through dial below digit  
Dial \*2#

**Banglalink number check**   
Simply open to your mobile’s dial option and dial the below digit  
Dial \*511#

**Robi number check**   
So you’re a user of Robi, see the below digit  
Dial \*140\*2\*4#

**Airtel number check**  
Just dial following code for own number check  
Dial \*121\*6\*3#

**Teletalk number check**  
If you’re a user of teletalk, you may have known that there is no option is teletalk to check your own number with dial some digit. To check your teletalk SIM number, you need to send a message.  
Dial \*551#  
Type “tar” and send to it 222 number.
