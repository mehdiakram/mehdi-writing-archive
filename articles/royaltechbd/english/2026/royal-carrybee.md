## 📦 Royal Carrybee

Seamless WooCommerce Shipping Integration for Bangladesh

**Why Choose Royal Carrybee?** Managing shipping in Bangladesh can be complex and time-consuming. **Royal Carrybee** integrates your WooCommerce store directly with Carrybee courier service, enabling **automated order creation, real-time tracking, and seamless delivery management**.

## 🚀 Powerful Features at Your Fingertips

Royal Carrybee comes with everything you need for efficient shipping management:

**🔗 Carrybee API v2.0 Integration:** Full integration with Carrybee’s latest API for reliable order management and tracking.

**📍 Cascading Location Dropdowns:** Smart City → Zone → Area selection at checkout for accurate delivery addresses.

**🏪 Store Management:** Manage multiple pickup stores directly from your WordPress dashboard.

**📦 One-Click Order Creation:** Create Carrybee shipping orders directly from WooCommerce order pages with a single click.

**🔄 Webhook Support:** Real-time order status updates via Carrybee webhooks for instant tracking information.

**🎨 Beautiful Admin Interface:** Modern, intuitive dashboard with SweetAlert2 notifications and DataTables integration.

**🧪 Sandbox & Production Modes:** Test your integration safely in sandbox mode before going live with production.

**🌐 Multilingual Ready:** Full translation support with Bengali (বাংলা) included out of the box.
