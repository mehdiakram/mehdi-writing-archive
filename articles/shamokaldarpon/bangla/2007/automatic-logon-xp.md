আপনার কম্পিউটারে একাধিক ব্যবহারকারী থাকতে পারে যার আলাদা পাসওয়ার্ডও থাকতে পারে। তবে আপনি চাইলে একটি নির্দিষ্ট ব্যবহারকারী সয়ংক্রিয়ভাবে কম্পিউটারে ঢুকতে পারবে। এজন্য রানে (StartRun) গিয়ে লিখুন CONTROL USERPASSWORDS2। এবার এখানে কোন ব্যবহারকারী সয়ংক্রিয়ভাবে কম্পিউটারে ঢুকতে পারবে তা নির্বাচন করে Users must enter a Username and password to use the computer বক্স থেকে চিক চিহ্ন তুলে দিন। Apply বাটনে ক্লিক করুন। এবার Automatically logged on ডায়ালগ বক্স আসবে। এখানে ঐ ব্যবহারকারীর পাসওয়ার্ড দিন এবং OK করুন। এবার User account এ OK করুন। এবার কম্পিউটার পুনরায় চালু (রিস্টার্ট) করে দেখুন নির্দিষ্ট ব্যবহারকারীর জন্য কম্পিউটার খুলে গেছে।  
আগের অবস্থায় ফিরে যেতে হলে Users must enter a Username and password to use the computer বক্সে চিক চিহ্ন দিলেই হবে।
