আমরা রানে গিয়ে উইন্ডোজের নির্ধারিত কিছু প্রোগ্রামের সংক্ষিপ্ত নাম লিখে ওকে করলে তা খোলে। আপনি চাইলে আপনার পছন্দের প্রোগ্রামগুলোর এমন শর্টকাট করে নিতে পারেন। এজন্য সি ড্রাইভে Shortcuts নামে একটি ফোল্ডার খুলুন। এবার মাই কম্পিউটার এর উপরে মাউসের ডান বাটন ক্লিক করে Properties এ ক্লিক করুন। এবার Advanced ট্যাব থেকে নিচের Environment Variables বাটনে ক্লিক করুন। এখন নিচের System Variables অংশে Path নির্বাচন করে নিচের Edit বাটনে ক্লিক করে Variable Value শেষে ;C:\Shortcuts লিখুন এবং Ok, Ok, Ok করুন। এখন যে প্রোগ্রামটি রানের মাধ্যমে চালু করতে চান সেই প্রোগামটির শর্টকাট Shortcuts ফোল্ডারে নাম পরিবর্তন করে সংক্ষিপ্ত করে রাখুন। যেমন ইন্টারনেট এক্সপ্লোরার এর নাম পরিবর্তন করে ie রাখুন। এবার রানে (Ctrl+R) গিয়ে ie লিখে ওকে করলে ইন্টারনেট এক্সপ্লোরার চালু হবে। এভাবে আরো প্রোগ্রাম যোগ করতে পারেন।
