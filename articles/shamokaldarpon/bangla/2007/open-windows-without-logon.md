আপনার কম্পিউটারে একাধিক ইউজার থাকতে পারে সেক্ষেত্রে ইউজার ও পাসওয়ার্ড দিয়ে কম্পিউটার খুলতে হয়। এমতবস্থায় অনান্য ইউজারের লগইন করার সুযোগ না দিয়ে সবসময় নির্দিষ্ট একটি ইউজারে কম্পিউটার খোলা যায়। এই সেটিংসের জন্য স্টার্ট থেকে রানে গিয়ে control userpasswords2 লিখে OK করুন তাহলে User Accounts প্রোপার্টিস শিট আসবে। এবার Users ট্যাব থেকে নির্দিষ্ট ইউজারটি সিলেক্ট করে Users must enter a user name and password to use this computer এর চেক বাটন আনচেক করুন এবং Apply করুন। এরপর উক্ত ইউজারের পাসওয়ার্ড দিয়ে OK করুন। এবার কন্ট্রোল প্যানেল থেকে User Accounts খুলুন এবং Change the Way Users Log On and Off -এ ক্লিক করে Use the Welcome Screen এবং Use Fast User Switching আনচেক করুন। এরপর থেকে কম্পিউটার খুললে কোন ইউজার বা পাসওয়ার্ড ছাড়ায় নির্দিষ্ট ঐ ইউজারে লগইন হবে।
