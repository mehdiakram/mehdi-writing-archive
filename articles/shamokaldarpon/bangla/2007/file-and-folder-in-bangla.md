কম্পিউটারের হার্ডডিক্স ড্রাইভের, ফাইল বা ফোল্ডারের নাম বাংলাতে লেখা যাবে। তবে এজন্য উইন্ডোজ ২০০০ বা এর পরের ভার্সন প্রয়োজন হবে কারণ উইন্ডোজ ২০০০ এবং এর পরবর্তী সংস্করনের উইন্ডোজ ইউনিকোডের উম্মুক্ত ফন্ট সমর্থন করে। তবে বাংলা লেখার জন্য অভ্র (ইউনিকোড কমপ্লান্ট বাংলা ইনপুট সফটওয়্যার) কীবোর্ডের প্রয়োজন। অনলাইন ([www.omicronlab.com/avrokeyboard](http://www.omicronlab.com/avrokeyboard)) থেকে বিনামূল্যে এই কীবোর্ড ডাউনলোড করতে পারবেন। এরই সাথে বিভিন্ন ইউনিকোড ভিত্তিক বাংলা ফন্টও ডাউনলোড করে নিতে পারেন। এরপর অভ্র সফটওয়্যারটি ইনষ্টল করে নিন। আপনার কম্পিউটারে যদি উইন্ডোজ এক্সপি সাভিস প্যাক ২ বা তার পরের ভার্সন থাকে তাহলে Vrinda নামে একটি ইউনিকোড ভিত্তিক উম্মুক্ত বাংলা ফন্ট আছে তা নিশ্চিত থাকুন। যা একই সাথে ইংরেজী এবং বাংলা সমর্থন করে। ফন্টটি না থাকলে অন্য যেকোন ইউনিকোড ভিত্তিক ওপেন টাইপ ফন্ট ইনষ্টল করে নিন। অভ্র সফটওয়্যারটি ইনষ্টল করলে কতগুলো ইউনিকোড ভিত্তিক ওপেন টাইপ ফন্ট ইনষ্টল হবে। আপনার কম্পিউটারে যদি উইন্ডোজ এক্সপি ইনষ্টল দেওয়া থাকে তাহলে Control Panel থেকে Display Properties খুলুন। এখানে Appearance ট্যাবে কিক করে Advanced বাটনে ক্লিক করুন। তাহলে Advanced Appearance ডায়ালগ বক্স আসবে এখান থেকে Item লিষ্ট থেকে Icon সিলেক্ট করুন। এবার লিষ্ট থেকে Vrinda বা অন্য যেকোন ইউনিকোড ভিত্তিক বাংলা ওপেন টাইপ ফন্ট সিলেক্ট করুন। (আপনার কম্পিউটারের উইন্ডোজ ২০০০ হলে Control Panel থেকে Display Properties খুলে, Appearance ট্যাবে কিক করে Advanced বাটনে ক্লিক করুন। এবং Advanced Appearance ডায়ালগ বক্স আসলে সেখান থেকে Item লিষ্ট থেকে Icon সিলেক্ট করুন। এবার লিষ্ট থেকে Vrinda বা অন্য যেকোন ইউনিকোড ভিত্তিক বাংলা ওপেন টাইপ ফন্ট সিলেক্ট করুন)। এবার আপনার কম্পিউটারে বাংলা ভাষা ব্যবহার করার জন্য কনফিগার করতে হবে। উইন্ডোজ এক্সপির জন্য Control Panel থেকে Regional and Language Options খুলুন এবং Language ট্যাব থেকে Install files for complex script and right-to-left language (including Thai) চেক বক্স চেক করে Ok করুন (আপনার কম্পিউটারের উইন্ডোজ 2000 এর ক্ষেত্র Control Panel থেকে Regional Options খুলুন। এবার General ট্যাব থেকে Language settings for the system অংশটির লিষ্ট থেকে Indic সিলেক্ট করে Ok করুন)। এক্ষেত্রে আপনার উইন্ডোজ ইনষ্টলারটির প্রয়োজন হতে পারে। সুতারাং উইন্ডোজের সিডি সাথেই রাখুন। এবার অভ্র কীবোর্ড লেআউট বাংলা করে ফাইল, ফোল্ডার বা ড্রাইভের নাম বাংলাতে লিখতে পারবেন। এই অভ্র কীবোর্ড এবং ইউনিকোড ভিত্তিক বাংলা ওপেন টাইপ ফন্টের সাহায্যে বাংলাতে ওয়েব পেজ তৈরী করতে পারেন অনায়াসে।
