[২-স্টেপ](http://www.shamokaldarpon.com/tag/2-step) ভেরিফিকেশন বা [২-ফ্যাক্টর](http://www.shamokaldarpon.com/?tag=two-factor) ভেরিফিকেশন সম্পর্কে আমরা কম বেশী সবার পরিচিত। সমপ্রতি জনপ্রিয় সামাজিক ওয়েবসাইট ফেসবুকও এই সেবাটি চালু করেছে। ২-স্টেপ ভেরিফিকেশন অ্যাকাউন্টের জন্য বাড়তি নিরাপত্তার দেবে। এতে পাসওয়ার্ড দিয়ে লগইন করার পরে মোবাইলে প্রাপ্ত কোড দ্বারা অ্যাকাউন্টে প্রবেশ করতে হবে। ফলে সাইবার ক্যাফে বা অন্যের কম্পিউটারে পাসওয়ার্ড চুরি গেলেও চোর আপনার অ্যাকাউন্টে প্রবেশ করতে পারবে না। গুগলে এই সেবাটি বেশ কিছুদিন আগে থেকে চালু করেছে।  
২-স্টেপ ভেরিফিকেশন করতে নিজের ধাপগুলো অবলম্বন করলেই হবে।

ধাপ১) গুগলে লগইন করে ডানের মেইল ঠিকানার উপরে ক্লিক করে Account settings ক্লিক করুন।  
![](https://lh4.googleusercontent.com/-XFkTTk7EOpQ/Tglx0-ZLUTI/AAAAAAAAAA8/hwH0MmIFHtA/s640/GOOGLE%2525202%252520Step%252520Verification-1.jpg)  
ধাপ২) Security অংশে Using 2-step verification লিংকে ক্লিক করুন।  
![](https://lh6.googleusercontent.com/-ZjK1a5INr1g/Tglx4EGQoiI/AAAAAAAAABI/5EhlaAuVF8M/s640/GOOGLE%2525202%252520Step%252520Verification-2.jpg)  
ধাপ৩) 2-step verification পেজে Set up 2-step verification বাটনে এ ক্লিক করুন।  
![](https://lh6.googleusercontent.com/-PlX8Zn-oreo/Tglx31bZjdI/AAAAAAAAABE/-uETQu4bc-Q/s640/GOOGLE%2525202%252520Step%252520Verification-3.jpg)  
ধাপ৪) এবার ড্রপ-ডাউন থেকে Text message (SMS) or voice call নির্বাচন করুন।  
![](https://lh5.googleusercontent.com/-Ar6Pq8RmN4M/Tglx38QUWvI/AAAAAAAAABM/POLNehJB3Bc/s640/GOOGLE%2525202%252520Step%252520Verification-4.jpg)  
ধাপ৫) এখন Add a mobile or landphone number where Google can send codes. এর নিচে ড্রপ-ডাউন লিষ্টে ক্লিক করে বাংলাদেশের নির্বাচন করুন।  
ধাপ৬) এবার ডানে মোবাইল নম্বর দিন (যেমন, 016xxxxxxxx, 017xxxxxxxx, 018xxxxxxxx, 019xxxxxxxx) এবং Send Code বাটনে ক্লিক করুন। এবার মোবাইলে প্রাপ্ত কোড নিচের বক্সে লিখে Verify বাটনে ক্লিক করুন এবং Next করুন। তাহলে নিশ্চিতকরণ পেজ আসবে এখানে Next করুন।  
![](https://lh5.googleusercontent.com/-A32jRA61ivE/Tglx-V3yDOI/AAAAAAAAABk/stWCzX6fM1E/s640/GOOGLE%2525202%252520Step%252520Verification-6.jpg)  
![](https://lh6.googleusercontent.com/-u9u0mF7hS5Y/Tglx-SlrRkI/AAAAAAAAABg/i7wz6IuJxZ8/s640/GOOGLE%2525202%252520Step%252520Verification-6b.jpg)  
ধাপ৭) যদি মোবাইল হারিয়ে যায় তাহলে অ্যাকাউন্টে লগইন করা যাবে না তাই বিকল্প ১০টি কোড দেওয়া আছে এই পেজে। প্রত্যেকটি কোড একবার করে ব্যবহার করা যাবে। পরবর্তিতে নতুন কোডও পাওয়া যাবে। তবে বিকল্প হিসাবে আরেকটি মোবাইল নম্বর যুক্ত করতে হবে। এজন্য Yes, I have a copy of my backup verification codes. এ ক্লিক করে Next বাটনে ক্লিক করুন।  
![](https://lh4.googleusercontent.com/-OlIcM8dHBnA/TglyBqdo-BI/AAAAAAAAABo/jMRqwrvBsCc/s640/GOOGLE%2525202%252520Step%252520Verification-7.jpg)  
ধাপ৮) এখানে আরেকটি মোবাইল নম্বর ভেরিফাই করে Next করুন।  
![](https://lh6.googleusercontent.com/-fLr7ChDmAcM/TglyBujON7I/AAAAAAAAABs/uVSs83962b4/s640/GOOGLE%2525202%252520Step%252520Verification-8.jpg)  
ধাপ৯) এখন Turn on 2-step verification বাটনে ক্লিক করলে ২-স্টেপ ভেরিফিকেশন সক্রিয় হবে এবং গুগল অ্যাকাউন্ট সাইন আউট হবে।  
![](https://lh6.googleusercontent.com/-BHKACjy2f44/TglyDidGh2I/AAAAAAAAABw/lhp0AsHEpyM/s640/GOOGLE%2525202%252520Step%252520Verification-9.jpg)  
ধাপ১০) এবার গুগলে লগইন করে দেখুন তাৎক্ষনাৎ মোবাইলে কোড এসেছে উক্ত কোড ২-স্টেপ ভেরিফিকেশন সম্পাপ্ত করুন।  
![](https://lh6.googleusercontent.com/-qTfQFp9YGK0/TglyE27ReeI/AAAAAAAAAB4/wecDrL6loas/s640/GOOGLE%2525202%252520Step%252520Verification-10.jpg)  
![](https://lh5.googleusercontent.com/-F22wffMEnDA/Tglx2IuLgBI/AAAAAAAAABA/evpj9Hs9rIc/s640/GOOGLE%2525202%252520Step%252520Verification-10a.jpg)  
এখন থেকে গুগলে লগইন করার সময় পাসওয়ার্ড দিলে আপনার মোবাইলে একটি কোড আসবে যা পরবর্তি পেজে লিখে লগইন সম্পন্ন করতে হবে। এসএমএস না আসলে ভয়েস কলের মাধ্যমেও কোড পাওয়া যাবে। মোবাইল কাছে না থাকলে Other ways to get verification code এ ক্লিক করে বিকল্প মোবাইলে কোড পাওয়া যাবে। অথবা পূর্বে সংরক্ষিত কোড দ্বারাও প্রবেশ করা যাবে।
