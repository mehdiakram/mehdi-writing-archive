ইংরেজীর পাশাপাশি বাংলা বা অন্য মাতৃভাষাতে মেইল করা এখন স্বাভাবিক একটা বিষয়। বাংলা ভাষাতে মেইল করতে হলে ডেক্সটপ সফটওয়্যার বা থার্ট পার্টি ওয়েবসাইটের মাধ্যমে বাংলা লিখতে হয়। তবে জিমেইল সম্প্রতি বাংলাসহ একাধিক ভাষাতে লিখার সুবিধা দিয়েছে। এতে ফনেটিকভাবে বাংলা ছাড়াও অনান্য ভাষাতে লিখা যাবে।   
এজন্য জিমেইলে লগইন করে যানে অপশনস থেকে Settings এ ক্লিক করলে General ট্যাবে থাকবে।  
![language](http://farm9.staticflickr.com/8196/8092836048_3fe9b6a640.jpg)  
এখানে Language অংশে Show all language options লিংকে ক্লিক করে Enable input tools চেক বক্স চেক করুন। পূর্ব থেকে Enable input tools চেক বক্স চেক করা থাকলে Edit tools এ ক্লিক করুন।  
![language](http://farm9.staticflickr.com/8336/8092836000_bbe6288c9f.jpg)  
এখন Input Tools পপআপ থেকে বাম পাশের প্যানেল থেকে পছন্দের ভাষা নির্বাচন করে ডানের প্যানেলে যুক্ত করুন এবং OK করুন।  
![language](http://farm9.staticflickr.com/8469/8092835958_faf8432269_z.jpg)  
এখন Settings এর General ট্যাবের নিচের Save Changes বাটনে ক্লিক করে সেভ করুন।  
তাহলে ডানে অপশনস বাটনে বামে একটি ল্যাঙ্গুয়েজের ড্রপ-ডাউন আসবে।  
![language](http://farm9.staticflickr.com/8052/8092830885_5ca2147ac5_z.jpg)  
কম্পোজে গিয়ে উক্ত ড্রপ-ডাউন ক্লিক করে ভাষা নির্বাচন করুন অথবা শর্টকাট হিসাবে Ctrl + shift + K চাপুন।  
![language](http://farm9.staticflickr.com/8335/8092835844_a5a0f54572_z.jpg)  
এরপরে ফনেটিক হিসাবে কিছু লিখে দেখুন তার সাজেশন আসছে যাতে ক্লিক করে উক্ত দরকারী শব্দটিতে ক্লিক করুন তাহলে তা চলে আসবে আর স্পেস চাপলে প্রথম শব্দটি আসবে।
