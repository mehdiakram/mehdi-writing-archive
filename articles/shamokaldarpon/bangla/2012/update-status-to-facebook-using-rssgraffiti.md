যারা ব্লগে বা টুইটারে নিয়মিত স্ট্যাটাস দিলে তা আবার ফেসুবকে দেওয়া ঝামেলা এবং সময় সাপেক্ষ ব্যপার। চাইলে ব্লগ বা টুইটারের ফিডের সাহায্যে স্ট্যাটাস ফেসবুকের পেজে, গ্রুপে বা প্রোফাইলে সয়ংক্রিয়ভাবে নেওয়া যায়। বিভিন্ন থার্টপার্টি সার্ভিসের মধ্যে আরএসএস গ্রাফীটি অন্যতাম।  
> আরএসএস গ্রাফীটির মাধ্যমে ফেসুবকে স্ট্যাটাস নিতে প্রথমে [www.rssgraffiti.com](http://www.rssgraffiti.com) সাইটে গিয়ে Get Started Now? বা Start Sharing বাটনে ক্লিক করুন তাহলে ফেসবুকের (<https://apps.facebook.com/rssgraffiti/>) অ্যাপসটি আসবে। ফেসবুকে লগইন করা না থাকলে লগইন করুন। সরাসসির অ্যাপসের ঠিকানাতে গেলেও হবে।  
![rssgraffiti](http://farm9.staticflickr.com/8295/7912391362_096f096d24_z.jpg)  
> এবার Go to App বাটনে ক্লিক করে Allow বাটনে ক্লিক করুন।  
> এবার Add New Publishing Plan লিংকে ক্লিক করে পৱানের একটি নাম লিখে Create Publishing Plan বাটনে ক্লিক করুন।  
> এখানে SOURCE এর ADD NEW বাটনে ক্লিক করে ব্লগের ফিডের ঠিকানা অথবা টু্‌ইটারের ইউজার নাম লিখে Add Source বাটনে ক্লিক করুন এবং প্রয়োজনীয় সেটিংস করে Save বাটনে ক্লিক করুন।  
> একইভাবে TARGET এর ADD NEW বাটনে ক্লিক করে প্রয়োজনীয় সেটিংস করে Save Change বাটনে ক্লিক করুন।  
> এবার SOURCE এবং TARGET এর মাঝে থাকা ডিজেবল হয়ে থাকা OFF বাটনে ক্লিক করে সক্রিয় করুন।  
ব্যাস এখন থেকে উক্ত ব্লগে বা টুইটারে কোন স্ট্যাটাস আপডেট হলে তা কিছুৰণের মধ্যে আপনার নির্ধারণ করা ফেসবুকের পেজে, গ্রপে বা প্রোফাইলে চলে আসবে।
