অনেক সময় আমরা নিজের মোবাইল সিমে থাকা নম্বরটা ভুলে যাই। এই অবস্থায় কয়েকটা সহজ কোড ডায়াল করেই নিজের নম্বরটা দেখা যায়। নিচে গ্রামীণফোন, রবি, বাংলালিংক, টেলিটক ও এয়ারটেলের জন্য নম্বর চেক করার উপায় বর্ণনা করা হল:

**নম্বর চেক করার নিয়ম**

গ্রামীণফোন (Grameenphone / GP)  
নিজের নম্বর জানতে সিম কার্ড থাকা মোবাইলের ডায়াল অপশনে গিয়ে টাইপ করুন  
\*2#  
এটা ডায়াল করার সাথে স্ক্রিনে আপনার নম্বর দেখাবে।

রবি (Robi)  
রবির ব্যবহারকারীদের একই কোড দিয়ে নিজের নম্বর দেখতে পারেন:  
*140*2\*4#  
এটা ডায়াল করলে আপনার নম্বর স্ক্রিনে প্রদর্শিত হবে।

বাংলালিংক (Banglalink)  
বাংলালিংক সিম থেকে নিচের কোড ডায়াল করুন:  
\*511#  
আপনার বাংলালিংক নম্বর তখনই স্ক্রিনে দেখাবে।

এয়ারটেল (Airtel)  
এয়ারটেল সিম ব্যবহারের ক্ষেত্রে নম্বর জানতে নিচের কোড ডায়াল করুন:  
*121*6\*3#  
স্ক্রিনে আপনার নম্বর চলে আসবে।

টেলিটক (Teletalk)  
টেলিটক সিমে সরাসরি কোড দিয়ে নম্বর জানা সম্ভব না হলেও, আপনাকে একটি মেসেজ পাঠাতে হবে:  
মেসেজে লিখুন tar এবং পাঠিয়ে দিন 222 নম্বরে।

| OPERATOR NAMES | USSD CODE TO CHEAK NUMBERS |
| --- | --- |
| Grameenphone | Dial \*2# |
| Airtel | Dial \*121\*6\*3# |
| Banglalink | Dial \*511# |
| Robi | Dial \*140\*2\*4# |
| Teletalk | Dial \*551# |
