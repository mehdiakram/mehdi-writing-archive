বিভিন্ন প্রয়োজনে ওয়েবসাইটের স্ক্রিনশট নিতে হয়। এজন্য মজিলা ফায়ারফক্সে বিভিন্ন অ্যাডঅন্স রয়েছে। তবে ফায়ারফক্সে ১৬ সংস্করণে অ্যাডঅন্স ছাড়াই সম্পূর্ণ পেজ বা ভিজিবল পেজের স্ক্রিনশট নেওয়া যায়।  
এজন্য Tools মেনু থেকে web developer/Developer toolbar এ ক্লিক করুন বা Shift+F2 চাপুন তাহলে নিচে ডেভেলপার টুলবার আসবে।  
![screenshot](http://farm9.staticflickr.com/8182/8073296764_af6c67fb54_z.jpg)

এখানে screenshot sdarponfull.png 0 true লিখে এন্টার করুন।  
![screenshot](http://farm9.staticflickr.com/8311/8073313608_b63f303c00_z.jpg)

তাহলে সম্পূর্ণ ওয়েবসাইটের স্ক্রিনশট সেভ হবে এবং তার লোকেশন দেখাবে।  
![screenshot](http://farm9.staticflickr.com/8040/8073313576_cc852eb7d3_z.jpg)

আর যদি ওয়েবাসইটের যতটুক দেখা যাচ্ছে ততটুকুর স্ক্রিনশট নিতে চান তাহলে এখানে screenshot sdarponvisible.png 0 false লিখে এন্টার করুন।  
![screenshot](http://farm9.staticflickr.com/8176/8073320409_d730de2c49_z.jpg)

তাহলে ওয়েবসাইটের যতটুক দেখা যাচ্ছে তার স্ক্রিনশট সেভ হবে এবং তার লোকেশন দেখাবে।  
![screenshot](http://farm9.staticflickr.com/8452/8073320367_b33aec1626_z.jpg)

এখানে sdarponvisible.png বা sdarponfull.png হচ্ছে কি নামে এবং কি ফরম্যাটে স্ক্রিনশটের ফাইলটি সেভ হবে তা নিদের্শ করে।
