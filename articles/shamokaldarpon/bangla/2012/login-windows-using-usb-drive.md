পাসওয়ার্ড প্রোটেক্টেড উইন্ডোজে পাসওয়ার্ড না লিখেও অটো-লগইন বা ফেস লগইন দ্বারাও লগইন করা যায়। এমনই আরেকটি পদ্ধতি হচ্ছে ইউএসবি ডিভাইসের মাধ্যমে লগইন করা। এজন্য ইউএসবি ডিভাইস কম্পিউটারের সাথে যুক্ত করলেই সয়ংক্রিয়ভাবে নিধারিত ইউজারে লগইন হবে। Rohos Logon Key নামের সফটওয়্যারটি <www.rohos.com/products/rohos-logon-free/> থেকে ফ্রি সংস্করণ ডাউনলোড করা যাবে।  
> প্রথমে সফটওয়্যারটির ডাউনলোড করে ইনষ্টল করুন।  
> এবার সফটওয়্যারটি চালু করে Setup USB Key বাটনে ক্লিক করুন।  
![usb key](http://farm9.staticflickr.com/8452/8049513094_b699d6e5c0_z.jpg)  
> এবার ইউজার নেম (ডিফল্ট হিসাবে চলতি ইউজারনেম আসবে যা পরিবর্তন করা যাবে), ইউএসবি ডিভাইস নির্বাচন করে নিচে নির্বাচিত ইউজারের পাসওয়ার্ড দিন এবং Setup USB Key বাটনে ক্লিক করুন। তাহলে একটি নিশ্চিতকরণ ম্যাসেজ আসবে তাতে OK করুন।  
![usb key](http://farm9.staticflickr.com/8318/8049513040_c9aedd2663.jpg)  
ব্যাস এবার উক্ত কম্পিউটারে লগইন স্ক্রিন আসলে বা আগে থেকে উক্ত ইউএসবি ডিভাইস যুক্ত থাকলে সয়ংক্রিয়ভাবে নির্দিষ্ট করা ইউজারে লগইন হবে। চাইলে পরবর্তীতে কী ডিজেবল করা যাবে।  
এই ইউএসবি লগইন কী উইন্ডোজের সকল সংস্করণের ওয়েলকাম স্ক্রিণ ছাড়াও রিমোট ডেক্সটপ এবং অ্যাকটিভ ডিরেক্টরি সমর্থন করে।
