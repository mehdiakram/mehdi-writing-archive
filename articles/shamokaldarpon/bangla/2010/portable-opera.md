জনপ্রিয় [ওয়েব ব্রাউজার](http://www.shamokaldarpon.com/tag/browser) অপেরার সম্প্রতি ১১ (আলফা) সংস্করণ অবমুক্ত হয়েছে। নতুন এই সংস্করণ দ্বারা তৃতীয়পক্ষের কোন সফটওয়্যারের সাহায্য ছাড়ায় [পোর্টেবল বা বহনযোগ্য](http://www.shamokaldarpon.com/?tag=portable) সংস্করণ বানানো যাবে ফলে উক্ত অপেরা ১১ ফ্লাশ ডিক্সসহ বিভিন্ন বহনযোগ্য ডিক্সে ব্যবহার করা যাবে ইনস্টলের ঝামেলা ছাড়ায়।  
অপেরা ১১ (আলফা) সংস্করণ [www.opera.com](http://www.opera.com/browser/next/) থেকে ডাউনলোড করা যাবে। অপেরা ১১ পোর্টেবল হিসাবে ব্যবহার করতে ডাউনলোড করা ইন্টলারে এ ডাবল ক্লিক করে Opera installer উইন্ডো আসলে Options বাটনে ক্লিক করে Install for এর ড্রপ-ডাউনে External Device নির্বাচন করে Install path এর Change বাটনে ক্লিক করে নির্দিষ্ট ফোল্ডার নির্বাচন করে Accept and Install বাটনে ক্লিক করলে পোর্টেবল সংস্করণ তৈরী হবে। অপেরা ১১ এর এই ফোল্ডারটি ফ্লাশ ডিক্সে বা অপটিক্যাল ডিক্সে রেখে ব্যবহার করা যাবে।
