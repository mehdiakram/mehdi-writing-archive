জনপ্রিয় ওয়েব ব্রাউজার [ফায়ারফক্স](http://www.shamokaldarpon.com/?tag=firefox) ব্যবহারকারীর [বুকমার্ক](http://www.shamokaldarpon.com/?tag=Bookmark), পাসওয়ার্ড, প্রিফারেন্স, হিস্টোরি, ট্যাব ইত্যাদি ব্যকআপ রাখা এবং [সিঙক্রোনাইজ](http://www.shamokaldarpon.com/?tag=Synchronize) করার সুবিধা দিয়েছে তাদের নতুন ৪.০ সংস্করণ থেকে। ফলে ফায়ারফক্স ব্যবহারকারীরা সহজেই এক কম্পিউটারের (বা ইউজারের) বুকমার্ক, পাসওয়ার্ড, প্রিফারেন্স, হিস্টোরি, ট্যাব ইত্যাদি অন্য কম্পিউটারে (বা ইউজারে) ব্যবহার এবং হালনাগাত করতে পারবে। এজন্য Tool মেনু থেকে Set Up Sync এ ক্লিক করে I’ve never used Sync before এ ক্লিক করতে হবে। এবার Create your Sync Account এ একাউন্ট তৈরীর জন্য ফরম পূরণ করে Next করতে হবে। এবার Secret Phrase লিখে করে Next করতে হবে এবং Browser Sync Preferences এ কম্পিউটারের নাম এবং সেটিংস নির্বাচন করে Next করে কনফার্ম কোড দিয়ে সমাপ্ত করুন, তাহলে সিঙক্রোনাইজ হবে এবং ফায়ারফক্সের সার্ভারে সংরক্ষিত থাকবে। এবার নতুন আরেকটি কম্পিউটারের সিঙক্রোনাইজ করতে Tool মেনু থেকে Set Up Sync এ ক্লিক করে I’m already using Sync on another computer এ ক্লিক করতে হবে। এখন User Name এবং Password দিয়ে Next করে পরবর্তি উইন্ডোতে Secret Phrase লিখে Next করুন। এরপরে Merge (বা Replace) নির্বাচন করে Next> Next করুন এবং কম্পিউটারের নাম এবং সেটিংস নির্বাচন করে Next এবং Finish করুন। এবার দেখুন আগের কম্পিউটারের বুকমার্ক, পাসওয়ার্ড, প্রিফারেন্স, হিস্টোরি, ট্যাব ইত্যাদি চলে এসেছে।  
পরবর্তিতে কোন পরিবর্তন করতে চাইলে Tool মেনু থেকে Options এ ক্লিক করে Sync ট্যাবে গিয়ে অথবা Tool মেনু থেকে Sync এ গিয়ে দরকারমত পরিবর্তন করতে পারেন।  
ফায়ারফক্সের নতুন সংস্করণটি (বিটা) [www.mozilla.com/en-US/firefox/beta/](http://www.mozilla.com/en-US/firefox/beta/) থেকে ডাউনলোড করা যাবে এছাড়াও সিঙক এ্যাড-অন্সটি <https://addons.mozilla.org/en-US/firefox/addon/10868/> থেকে ইনস্টল করে ৩.৫ এবং ৩.৬ সংস্করণে ব্যবহার করা যাবে।
