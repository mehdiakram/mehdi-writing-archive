১০০০টি slash-style AI prompt code-এর dictionary। এখানে শুধু কোড নয়, প্রতিটি কোড এর অর্থ, কীভাবে output পরিবর্তন হয়, কোন category-তে পড়ে, example এবং practical usage দেওয়া আছে।
এগুলোকে universal secret command ভাবা উচিত নয়; এগুলো shorthand হিসেবে মূল prompt-এ ব্যবহার করা হয়।

## কীভাবে ব্যবহার করবেন

**মূল formula:**  
[Subject] + [Environment] + [Composition] + [Lighting] + [Style] + [Camera/Technical] + [Mood] + [Restrictions]
  
  
**উদাহরণ:**  
`/cinematic /photorealistic /85mm /goldenhour /shallowdof /luxurylook`  
A confident Bangladeshi businessman standing in a modern glass office, natural pose
  
  
**আরেকটি:**  
`/productshot /softbox /50mm /negative_space /premium /clean_background`  
A premium black wireless earbud case on a dark marble table, commercial product photography

**একসাথে কতগুলো code ব্যবহার করা উচিত?**  
সাধারণত ৩–৮টি compatible modifier যথেষ্ট। একই category থেকে অতিরিক্ত contradictory code দিলে output অস্পষ্ট হতে পারে।
যেমন `/lowkey` এবং `/highkey` একসাথে না দেওয়াই ভালো।
