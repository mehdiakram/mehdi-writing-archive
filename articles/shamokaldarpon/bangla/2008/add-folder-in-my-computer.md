উইন্ডোজে মাই কম্পিউটার খুললে সাধারণত বিভিন্ন ড্রাইভ দেখা যায়। এছাড়াও শেয়ার ডকুমেন্ট এবং কন্ট্রোল প্যানেলও থাকে। এখানে সাধারণত কোন ফোল্ডার বা প্রোগ্রাম যোগ করা যায় না। আর কন্ট্রোল প্যানেলেও তেমনই নির্দিষ্ট কন্ট্রোল ছাড়া কোন প্রোগ্রাম যোগ করা যায় না। কিন্তু ফোল্ডার২মাইপিসি সফটওয়্যার দ্বারা মাই কম্পিউটারে এবং কন্ট্রোল প্যানেলে ইচ্ছামত ফোল্ডার এবং প্রোগ্রাম যুক্ত করতে পারেন। এজন্য www.download.com বা http://folder2mypc.uptodown.com বা http://eng.softq.org/Folder2mypc ওয়েব সাইট থেকে ফোল্ডার২মাইপিসি সফটওয়্যারটি (৩৭৬ কিলোবাইট) ডাউনলোড করে ইনষ্টল করুন। এবার সফটওয়্যারটি খুলে Create>Folder থেকে Create a shotcut for folder অংশে ডানে ব্রাউজ বাটনে ক্লিক করে পছন্দের ফোল্ডার সিলেক্ট করে ওকে করুন। এবার নিচে Display as (Title) এ ফোল্ডারের নাম লিখুন (যা মাই কম্পিউটারে প্রদর্শন করবে) এবং Tip for Folder অংশে টিপ লিখুন (যা ফোল্ডারের উপরে মাউস ধরলে দেখা যাবে)। এবার Create Type of Folder এ আপনার পছন্দমত নির্বাচন করুন। ইচ্ছা হলে নিচে Use custom icon চেক করে পছন্দের আইকন নিতে পারেন। এবার নিচে Create বাটনে ক্লিক করে ওকে করলে মাই কম্পিউটারে উক্ত ফোল্ডারের শর্টকাট যোগ হবে। এছাড়াও প্রোগ্রাম যোগ করতে চাইলে Create>Application থেকে প্রোগ্রাম যোগ করতে পারবেন। আর পরবর্তীতে কোন কিছু পরিবর্তন বা মুছে ফেলেতে পারবেন Edit / Remove ট্যাব থেকে।
