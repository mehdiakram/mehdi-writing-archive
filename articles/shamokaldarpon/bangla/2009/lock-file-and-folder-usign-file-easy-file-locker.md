কম্পিউটারে একাধিক ব্যবহারকারী থাকলে গুরুত্বপূর্ণ ফাইল বা ফোল্ডারের নিরাপত্তা নিয়ে চিন্তিত থাকেতে হয়। ফোল্ডার পাসওয়ার্ড দ্বারা লক করার বিভিন্ন ফ্রি সফটওয়্যার আছে তবে এগুলোর মধ্যে ইজি ফাইল লকার অন্যতম এবং বেশ নির্ভরযোগ্য। মাত্র ২২৬ কিলোবাইটের ফ্রিওয়্যার এই সফটওয়্যারটি [www.xoslab.com থেকে](http://www.xoslab.com/)  ডাউনলোড করে নিন। এবার সফটওয়্যারটি ইনস্টল করে System মেনু থেকে পাসওয়ার্ড সেট করে নিন। এবার ফোল্ডার লক করতে Edit মেনু থেকে Add Folder এ ক্লিক করুন এবং Setting ডায়ালগ বক্স থেকে ব্রাউজ বাটনে ক্লিক করে যে ফোল্ডারটি লক করতে চান সেটি নির্বাচন করুন। এবার Accessable, Writeable, Deleteable, Visible থেকে দরকারী অপশনগুলো নির্বাচন করে Ok করুন। ব্যাস আপনি যদি Accessable নির্বাচন না করেন তাহলে উক্ত ফোল্ডার কেউ পড়তে পারবে না। এভাবে আপনি ইচ্ছামত ফাইল বা ফোল্ডার বিভিন্নভাবে লক করে রাখতে পারবেন। পরবর্তিতে সেট করা ফাইল/ফোল্ডারের এই সেটিংস পরিবর্তন, বা মুছতে পারবেন। আর দারুন ব্যাপার হচ্ছে সফটওয়্যারটি পাসওয়ার্ড ছাড়া আনইনস্টল করা যাবে না।
