অনেক সময় এ্যানিমেটেড জিফ ছবির আয়তন ছোট বা বড় করার প্রয়োজন পরে। ছোট্ট একটি সফটওয়্যার দ্বারা এই কাজটি করা যায়। মাত্র ৫২৪ (৬২৭) কিলোবাইটের ফ্রিওয়্যার, পোর্টেবল এই সফটওয়্যারটি <http://ashongsoft.com/gif-resizer.html> থেকে ডাউনলোড করে নিন। এবার সফটওয়্যারটি চালু করে Source GIF Image file থেকে এ্যনিমেটেড ছবিটি আনুন এবং কোথায় সেভ করবেন তা New GIF Image file এ নির্বাচন করুন। এবার Width এবং Height ঠিক করে Resize বাটনে ক্লিক করলেই নতুন সাইজে ছবিটি তৈরী হবে।
